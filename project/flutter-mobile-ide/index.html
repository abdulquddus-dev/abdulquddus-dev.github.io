Flutter Mobile IDE — بيئة تطوير Flutter على هاتفك

محرر أكواد + شجرة ملفات + معاينة تفاعلية حيّة، داخل تطبيق أندرويد واحد

Android قيد التطوير المستمر FlutterDartRiverpodمفتوح المصدرمجاني

Flutter Mobile IDE بيئة تطوير Flutter مصغّرة تعمل بالكامل على الهاتف: افتح مشروعًا من ذاكرة جهازك، عدّل ملفاتك في محرر أكواد احترافي، وشاهد شاشاتك تعمل معاينةً تفاعلية حقيقية (أزرار تعمل، وتنقّل بين الشاشات، وsetState يعيد الرسم فعليًا) دون حاسوب.

أبرز المزايا

  • محرر أكواد احترافي: تلوين نحوي لـ Dart، أرقام أسطر، إزاحة تلقائية، إغلاق تلقائي للأقواس، بحث واستبدال، وتبويبات متعددة.
  • إدارة المشاريع: افتح مشروعًا من الجهاز أو أنشئ مشروعًا جديدًا ببنية قياسية، مع استعادة آخر مشروع تلقائيًا وقائمة مشاريع حديثة، وتعديل تبعيات pubspec.yaml من الواجهة.
  • شجرة ملفات كاملة: إنشاء وحذف وإعادة تسمية ونسخ وقص ولصق للملفات والمجلدات.
  • معاينة حيّة تفاعلية: مُفسِّر Dart مُقيَّد يبني ودجتس Flutter حقيقية من كودك مباشرة، وتُرسم بنفس محرك Flutter.
  • بحث عبر المشروع: ابحث في كل ملفات المشروع من مكان واحد.
  • أخطاء أثناء الكتابة: خطوط حمراء متعرجة بمحلل Dart الرسمي، وتبويب Problems يفرّق بين «خطأ في كودك» و«المعاينة لا تدعمه بعد».
  • إكمال تلقائي وتنسيق: اقتراحات للودجتس ومعاملاتها، وتنسيق كود Dart بضغطة.
  • Git بسيط (تجريبي): لوحة Git مدمجة تعمل بمكتبة Dart خالصة، فلا حاجة لثنائي git على الهاتف.
  • واجهة عربية بالكامل بثيم داكن وفاتح وإعدادات تُحفظ بين الجلسات.

كيف يعمل؟ (بصراحة تقنية)

تنبيه مهم: هذا التطبيق لا يبني ولا يشغّل مشروع Flutter كاملًا كما يفعل Android Studio، لأن ذلك يتطلب Dart SDK وأدوات Gradle لا يمكن تشغيلها داخل تطبيق على الهاتف. البديل المُنفَّذ هو مُفسِّر يبني الودجتس مباشرة للمعاينة، ويدعم حاليًا مجموعة جزئية من صياغة Dart (ودجتس Stateless/Stateful، setState، Navigator، حلقات for، ودوال مساعدة، وasync/await مبسّط). أما حزم pub الخارجية فلا تُنفَّذ في المعاينة، وقائمة الودجتس المدعومة محدودة وتتوسع تدريجيًا. التطبيق قيد تطوير مستمر بإصدار مبكر (0.1.0)، فقد تصادف أخطاء.

طريقة التثبيت

  1. نزّل ملف APK من صفحة الإصدارات في GitHub (زر التحميل أدناه).
  2. اسمح لهاتفك بالتثبيت من مصدر خارجي عند الطلب، ثم ثبّت التطبيق.
  3. امنح التطبيق صلاحية «الوصول إلى كل الملفات» ليتمكن من فتح مجلدات المشاريع وحفظ تعديلاتك.
  4. اضغط «فتح مشروع من الجهاز»، واختر مجلد مشروع Flutter، وابدأ التعديل.

أسئلة شائعة

ما هو Flutter Mobile IDE؟

تطبيق أندرويد مجاني يتيح لك كتابة مشاريع Flutter وتعديلها من هاتفك: محرر أكواد، شجرة ملفات، بحث، Git، ومعاينة تفاعلية حيّة لشاشاتك أثناء الكتابة.

هل يشغّل مشاريع Flutter الكاملة كما يفعل Android Studio؟

لا. يستخدم مُفسِّر Dart مُقيَّدًا يبني ودجتس Flutter حقيقية للمعاينة، ضمن مجموعة جزئية من صياغة Dart. الحدود موثّقة بصراحة في المشروع، وتتوسع مع كل إصدار.

كيف أحمّله؟

من صفحة الإصدارات في GitHub: نزّل ملف APK وثبّته على هاتف أندرويد.

هل هو مجاني ومفتوح المصدر؟

نعم، مجاني بالكامل وكوده المصدري متاح على GitHub.

لماذا يطلب صلاحية التخزين؟

ليفتح مجلد مشروع Flutter من ذاكرة الهاتف ويقرأ ملفاته ويحفظ تعديلاتك عليه.
